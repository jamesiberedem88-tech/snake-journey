## Snake Journey Game

## Description
Snake journey gme is a C++ console-game based where the player controls a snake, collects food to grow longer, and tries to achieve the highest score.

## Features
- Smooth snake movement 
- unlimited food generation until Game over 
- Game Over Detection

## Technologies used 
- C++

## COntrols
- w - Move up
- A - Move left
- S - Move Down
- D - Move Right
- Q - quit
